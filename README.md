# dataset-nlftp

国土数値情報（nlftp.mlit.go.jp）の行政区域・人口集中地区・将来推計人口・鉄道・駅別乗降客数・医療機関・医療圏・学校・福祉施設・市町村役場等及び公的集会施設・バス・洪水浸水想定区域・雨水出水（内水）浸水想定区域・多段階浸水想定・津波浸水想定・土砂災害警戒区域・急傾斜地崩壊危険区域・地すべり防止区域・砂防指定地・災害危険区域・高潮浸水想定区域・土地利用・用途地域・通学区域・過疎地域の GIS データを DuckLake カタログ化したデータセット。

## データ出典

国土交通省「国土数値情報ダウンロードサイト」が公開する以下のデータを使用する。

行政区域データ（N03、令和7年版 / 世界測地系）から全国の都道府県・市区町村の境界ポリゴンを収録する。座標参照系は EPSG:4612（JGD2011）。

- 行政区域データ（N03-2025）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2025.html

人口集中地区は「人口集中地区データ（A16、令和2年国勢調査）」を使用する。国勢調査の基本単位区のうち人口密度が高い区域を市区町村ごとにまとめた区域と、その人口・面積・世帯数を収録する。区域は原典が行政区域データに合わせて修正したもの。座標参照系は EPSG:6668（JGD2011）。人口集中地区データは整備年度によって使用許諾条件が異なり、1995年（平成7年）以降のものが商用可のため、令和2年国勢調査に基づく版のみを収録する。

- 人口集中地区データ（A16-2020）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A16-2020.html

将来推計人口は「1kmメッシュ別将来推計人口データ（R6国政局推計）」と「500mメッシュ別将来推計人口データ（R6国政局推計）」を使用する。推計値は総務省「令和2年国勢調査」と国立社会保障・人口問題研究所「日本の地域別将来推計人口（令和5年推計）」に基づき、2020〜2070年の5年ごとの値を収録する。500mメッシュは同じ推計を細かい粒度で集計し直したもので、全国・都道府県の合計は1kmメッシュ版と一致する。メッシュポリゴンの座標参照系は EPSG:6668（JGD2011）。

- 1kmメッシュ別将来推計人口（R6国政局推計）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-mesh1000r6.html
- 500mメッシュ別将来推計人口（R6国政局推計）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-mesh500r6.html

鉄道データは「鉄道データ（N02、令和6年版）」を使用する。全国の鉄道路線・駅を収録する。座標参照系は EPSG:6668（JGD2011）。

- 鉄道データ（N02-2024）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2024.html

駅別乗降客数は「駅別乗降客数データ（S12、2024年度版）」を使用する。全国の鉄道駅について 2011〜2024年度の1日あたり乗降客数を収録する。原典は鉄道事業者の提供資料で、各社が独自に算出した数値のため統一的な基準に基づくものではない。座標参照系は EPSG:6668（JGD2011）。

- 駅別乗降客数データ（S12-2024）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-S12-2024.html

医療機関データは「医療機関データ（P04、第3.0版 / 令和2年）」を使用する。全国の病院・診療所・歯科診療所の位置・診療科目・病床数・開設者分類を収録する。座標参照系は EPSG:6668（JGD2011）。

- 医療機関データ（P04-v3.0）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P04-v3_0.html

医療圏は「医療圏データ（A38、2020年度版）」を使用する。医療法に基づいて都道府県が定める医療計画の中で設定された一次・二次・三次医療圏の区域と、二次医療圏ごとの面積・人口を収録する。区域は原典が行政区域データ（N03）から作成したもの。座標参照系は EPSG:6668（JGD2011）。

- 医療圏データ（A38-2020）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A38-2020.html

学校データは「学校データ（P29、第2.0版 / 令和3年）」を使用する。全国の小学校・中学校・高等学校・大学・幼稚園・特別支援学校等の位置・学校分類・管理者を収録する。座標参照系は EPSG:6668（JGD2011）。

- 学校データ（P29-v2.0）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P29-v2_0.html

バスは「バス停留所データ（P11、第3.0版 / 令和4年度）」と「バスルートデータ（N07、令和4年度）」を使用する。全国のバス停留所の位置・事業者・系統と、バス路線の経路を収録する。座標参照系は EPSG:6668（JGD2011）。いずれも旧版（P11 第2.0版 / 平成22年度・N07 平成23年度）は使用許諾条件が非商用のため使わない。

- バス停留所データ（P11-v3.0）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P11-v3_0.html
- バスルートデータ（N07-2022）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N07-2022.html

洪水浸水想定区域データは「洪水浸水想定区域データ（河川単位）（A31a、2025年度）」を使用する。全国の洪水予報河川・水位周知河川およびその他河川の浸水想定区域のうち、想定最大規模（L2）の浸水区域ポリゴンを収録する（計画規模・浸水継続時間・家屋倒壊等氾濫想定区域は収録しない）。座標参照系は EPSG:6668（JGD2011）。

- 洪水浸水想定区域データ（河川単位）（A31a-2025）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A31a-2025.html

雨水出水（内水）浸水想定区域は「雨水出水（内水）浸水想定区域データ（A51、2025年度版）」を使用する。水防法に基づいて市町村等が設定した内水氾濫の浸水想定を、浸水深の区分ごとのポリゴンとして収録する。座標参照系は EPSG:6668（JGD2011）。使用許諾条件はオープンデータ（CC BY 4.0）で全国一律のため、都道府県による絞り込みは無い。配布は都道府県単位だが区域を設定するのは市町村等なので、収録の単位は市区町村になる。整備年度は市区町村ごとに異なる。

- 雨水出水（内水）浸水想定区域データ（A51-2025）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A51-2025.html

多段階浸水想定は「多段階浸水想定データ（A53、2025年度版）」を使用する。河川管理者が作成した多段階の浸水想定図を、降雨規模（1/10・1/30・1/50・1/100 と河川整備の計画規模 1/150 または 1/200）ごとに浸水深の区分のポリゴンとして収録する。座標参照系は EPSG:6668（JGD2011）。使用許諾条件はオープンデータ（CC BY 4.0）で全国一律のため、都道府県による絞り込みは無い。配布は地方整備局等（81 北海道開発局 〜 89 九州地方整備局）単位で、収録の単位は水系の対象区間になる。整備年度は対象区間ごとに異なる。

- 多段階浸水想定データ（A53-2025）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A53-2025.html

津波浸水想定は「津波浸水想定（A40、第2.1版）」を使用する。津波防災地域づくり法に基づいて都道府県が設定した浸水想定を、浸水深の区分ごとのポリゴンとして収録する。座標参照系は EPSG:6668（JGD2011）。津波浸水想定データは原典資料を作成した都道府県ごとに使用許諾条件が異なるため、配布ページで「オープンデータとして利用可（商用利用可・再配信可）」とされた都道府県のみを収録する。整備年度は都道府県ごとに 2016〜2022年度と幅がある。

- 津波浸水想定（A40-v2.1）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A40-v2_1.html

土砂災害警戒区域は「土砂災害警戒区域（A33、2025年度版）」を使用する。土砂災害防止法第7条に基づいて都道府県が指定した土砂災害警戒区域（イエローゾーン）・土砂災害特別警戒区域（レッドゾーン）を、急傾斜地の崩壊・土石流・地滑りという現象の種類ごとの区域ポリゴンとして収録する。データ基準日は2025年8月1日。座標参照系は EPSG:6668（JGD2011）。土砂災害警戒区域データは原典資料を作成した都道府県ごとに使用許諾条件が異なるため、配布ページで「オープンデータとしての利用可（商用利用可・再配信可）」とされた都道府県のみを収録する。

- 土砂災害警戒区域（A33-2025）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A33-2025.html

急傾斜地崩壊危険区域は「急傾斜地崩壊危険区域（A47、2021年度）」を使用する。急傾斜地の崩壊による災害の防止に関する法律（急傾斜地法）第3条に基づいて都道府県知事が指定した区域を、区域ポリゴンとして収録する。座標参照系は EPSG:6668（JGD2011）。急傾斜地崩壊危険区域データは原典資料を作成した都道府県ごとに公開条件が異なるため、提供元が配布する都道府県別の一覧で「オープンデータにて公開」とされた23都道府県のみを収録する。

- 急傾斜地崩壊危険区域（A47-2021）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A47-2021.html

地すべり防止区域は「地すべり防止区域（A46、2021年度）」を使用する。地すべり等防止法第3条に基づいて主務大臣が指定した区域を、区域ポリゴンとして収録する。座標参照系は EPSG:6668（JGD2011）。所管省庁が国土交通省・農林水産省農村振興局・林野庁の3つに分かれており、公開条件も都道府県 × 所管省庁ごとに異なるため、提供元が配布する一覧で「オープンデータにて公開」とされた79の組み合わせ（43都道府県）のみを収録する。

- 地すべり防止区域（A46-2021）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A46-2021.html

砂防指定地は「砂防指定地（A52、2023年度）」を使用する。砂防法第2条に基づいて国土交通大臣が指定した土地を、指定地ポリゴンとして収録する。座標参照系は EPSG:6668（JGD2011）。使用許諾は CC BY 4.0 で都道府県ごとの絞り込みは要らないが、提供元が原典資料の提供を受けた24都道府県しか配布されていない。データの時点は都道府県ごとに違う（平成30年3月末〜令和5年6月末）。

- 砂防指定地（A52-2023）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A52-2023.html

災害危険区域は「災害危険区域（A48、2021年度）」を使用する。建築基準法第39条に基づいて地方公共団体が条例で指定した区域を、区域ポリゴンとして収録する。座標参照系は EPSG:6668（JGD2011）。指定するのは都道府県と市町村の両方で、公開条件も指定した地方公共団体ごとに異なるため、提供元が配布する一覧で「オープンデータにて公開」とされた団体が指定した区域のみを収録する（35都道府県・550市区町村）。

- 災害危険区域（A48-2021）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A48-2021.html

高潮浸水想定区域は「高潮浸水想定区域（A49、2024年度版）」を使用する。水防法に基づいて都道府県が設定した想定し得る最大規模の高潮による浸水想定を、浸水深の区分ごとのポリゴンとして収録する。座標参照系は EPSG:6668（JGD2011）。高潮浸水想定区域データは原典資料を作成した都道府県ごとに使用許諾条件が異なるため、配布ページで「オープンデータとして利用可（商用利用可・再配信可）」とされた都道府県のみを収録する。整備年度は都道府県ごとに 2020〜2024年度と幅がある。

- 高潮浸水想定区域（A49-2024）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A49-2024.html

土地利用は「都市地域土地利用細分メッシュデータ（L03-b-u、第3.1版 / 令和3年度）」を使用する。3次メッシュを 1/10 に細分した 100m 四方の区画ごとに、地形図と衛星画像の判読による土地利用種別を収録する。整備範囲は都市地域に限られ、令和3年度版は北海道と東北北部が対象外。座標参照系は EPSG:6668（JGD2011）。

- 都市地域土地利用細分メッシュデータ（L03-b-u 第3.1版）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-L03-b-u-v3_1.html

福祉施設データは「福祉施設データ（P14、第2.1版 / 令和3年度）」を使用する。全国の保護施設・老人福祉施設・障害者支援施設・身体障害者社会参加支援施設・児童福祉施設・母子父子福祉施設等の位置・分類（大／中／小）・管理者を収録する。全国版が無く都道府県別に配布されるため47都道府県分を統合する。座標参照系は EPSG:6668（JGD2011）。一部の都道府県・市区町村は利用規約と異なる利用条件が付されているため、利用時は提供元の利用制限を確認すること。

## テーブル: prefecture

都道府県の行政区域境界ポリゴン。N03（令和7年）の行政区域データを都道府県単位で集約したもの。

- prefecture_code: 都道府県コード（2桁）
- prefecture_name: 都道府県名
- geometry: 境界ポリゴン（EPSG:4612 / JGD2011）

## テーブル: municipality

市区町村の行政区域境界ポリゴン。N03（令和7年）の行政区域データを市区町村単位で集約したもの。同一自治体の飛び地等は ST_Union_Agg で統合済み。政令指定都市は区単位で収録され、行政区名を ward_name に持つ。

- lg_code: 全国地方公共団体コード（5桁、都道府県2桁 + 市区町村3桁）
- prefecture_code: 都道府県コード（2桁）
- prefecture_name: 都道府県名
- county_name: 郡名
- city_name: 市区町村名
- ward_name: 行政区名（政令指定都市のみ。他は NULL）
- geometry: 境界ポリゴン（EPSG:4612 / JGD2011）

### 人口集中地区データの注意点

1 行 = 1 地区で、地区が飛び地に分かれる分は 1 行のマルチポリゴンにまとまっている。同じ市区町村に複数の地区が設定されることがあり（最多は豊田市と神戸市北区の 9 地区）、その場合は人口の多い順に符号が振られた別々の行になる。一意なのは did_code で、lg_code は重複する。市区町村単位で見るときは lg_code で集約する。

人口の少ないメッシュは原典で秘匿処理の対象になり、65歳以上人口が近隣のメッシュへ移される。総人口は秘匿処理前の値（PTN）を収録しているのに対し、高齢化率の分子となる65歳以上人口（PTC）は秘匿処理後の値なので、メッシュ単位の高齢化率は秘匿された側で低く、移された先で高く出る。elderly_ratio_2025 が 0 になる行（population_2025 は正）は1kmで5.0%・500mで9.6%、100 を超える行は1kmで0.5%・500mで1.2%ある。人口の多いメッシュでも起きるため（500mの100超えのうち335行は population_2025 が10以上、最大100.1）、人口での足切りでは取り除けない。高齢化率はメッシュ単位で読まず、対象範囲を総人口で重み付けして平均する（`sum(population_2025 * elderly_ratio_2025) / sum(population_2025)`）。合計すれば移された分が戻り、都道府県単位の高齢化率は1kmメッシュ版と小数第3位まで一致する。

- 配布は GeoJSON・シェープファイル・GML の3形式だが、シェープファイルの .dbf は CP932 で DuckDB がそのまま読めないため GeoJSON を使う。zip には一次（`_1`）・二次（`_2`）・三次（`_3`）の3ファイルが入る。
- 一次医療圏の区域は市区町村と同じなのでジオメトリを取り込まず、市区町村と二次医療圏の対応だけを Parquet にする（区域は boundary スキーマが持つ）。
- 変換済み Parquet（`data/medical_area/{primary,secondary,tertiary}/`）が残っていれば該当都道府県はスキップされる。年次更新時はパイプラインの版（A38-20 等）とページの URL を更新し、`data/medical_area/` を削除してから再実行する。
- 対象都道府県を絞る場合は `NLFTP_MEDICAL_AREA_PREFECTURES`（カンマ区切り、例: `NLFTP_MEDICAL_AREA_PREFECTURES=13,16`）を指定する。

人口集中地区データ（A16）の更新運用:

- 使用許諾条件は整備年度によって分かれる（1995年以降が商用可）。パイプライン実行時に配布ページを取得して記載が変わっていないことを確かめ、変わっていればエラーで停止する。
- 1960年から5年ごとの過年度整備分と都道府県別の zip も同じページに並ぶため、取り込む年度の全国版 zip だけを拾う。見つからなければエラーで停止する。
- 配布は GeoJSON・シェープファイル・GML の3形式だが、GeoJSON は座標参照系（EPSG:6668）の宣言を持つのでこれを使う。
- 変換済み Parquet（`data/did/A16-20.parquet`）が残っていればダウンロードごとスキップされる。国勢調査が実施されて新しい版が出たときはパイプラインの版（A16-20 等）とページの URL を更新し、`data/did/` を削除してから再実行する。

過疎地域データ（A17）の更新運用:

- 使用許諾条件はデータ項目全体に付き、都道府県ごとの区分は無い。パイプライン実行時に配布ページを取得して「商用可」の記載が残っていることを確かめ、記載が変わっていればエラーで停止する（都道府県が原典を作るデータは条件付き公開の区分が後から足されることがあるため）。ダウンロード一覧から読み取れた都道府県単位のファイルが46と一致しない場合も停止する。
- 1970年から2016年までの過年度整備分も同じページに並ぶため、取り込む年度の zip だけを拾う。
- 配布は GeoJSON・シェープファイル・GML の3形式だが、シェープファイルの .dbf は CP932 で DuckDB がそのまま読めないため GeoJSON を使う。
- 変換済み Parquet（`data/depopulated_area/parquet/`）が残っていれば該当都道府県はスキップされる。新しい版が出たときはパイプラインの版（A17-17 等）とページの URL を更新し、`data/depopulated_area/` を削除してから再実行する。
- 対象都道府県を絞る場合は `NLFTP_DEPOPULATED_AREA_PREFECTURES`（カンマ区切り、例: `NLFTP_DEPOPULATED_AREA_PREFECTURES=13,47`）を指定する。

## ライセンス

国土数値情報の利用約款および政府標準利用規約（第2.0版）に従う。出典データは加工して利用している。洪水浸水想定区域データ（A31a、2021年度以降版）とバスルートデータ（N07、令和4年度版）のライセンスは CC BY 4.0。バス停留所データ（P11）は第3.0版（令和4年度）のみが国土数値情報ダウンロードサイトコンテンツ利用規約に基づくオープンデータで、第2.0版（平成22年度）は非商用のため使用していない。都市地域土地利用細分メッシュデータ（L03-b-u）は令和3年度版・平成28年度版が利用規約に基づくオープンデータ、それ以前の版も商用可。

用途地域データ（A29）は国土数値情報の利用約款に加えて各市区町村が定めた利用条件が適用されるため、提供元が配布する「公開に関する利用条件」で「オープンデータ公開可」とされた市区町村のみを収録している。

津波浸水想定（A40）は国土数値情報の利用約款に加えて各都道府県が定めた利用条件が適用されるため、配布ページで「オープンデータとして利用可（商用利用可・再配信可）」とされた都道府県のみを収録している。条件付公開・商用利用不可・提供不可の都道府県は収録していない。

土砂災害警戒区域（A33、2025年度版）は CC BY 4.0（一部制限）で、国土数値情報の利用約款に加えて各都道府県が定めた利用条件が適用される。配布ページで「オープンデータとしての利用可（商用利用可・再配信可）」とされた都道府県のみを収録し、条件付公開の県は収録していない。

急傾斜地崩壊危険区域（A47、2021年度）は CC BY 4.0（一部制限）で、国土数値情報の利用約款に加えて各都道府県が定めた利用条件が適用される。提供元が配布する都道府県別の一覧で「オープンデータにて公開」とされた都道府県のみを収録し、条件付き公開の県は収録していない。
